### Explanations (8), given on request from the approved table, with no LLM

| ID | Reply |
|---|---|
| E1 | Gans falsch {de:gans_falsch} is a pun on 'ganz falsch' (completely wrong). Gans means goose. The duck is not one. |
| E2 | Ente gut, alles gut {de:ente_gut} is a pun on 'Ende gut, alles gut' (all's well that ends well), with a duck in it. |
| E3 | Zeitungsente {de:zeitungsente} means a hoax story, literally 'newspaper duck'. A false story, not a real duck. |
| E4 | Entenschuldigung {de:entenschuldigung} is a pun on 'Entschuldigung' (sorry, excuse me). The duck is sorry. |
| E5 | Quaktuell {de:quaktuell} is a pun on 'aktuell' (current, up to date). Very current duck news. |
| E6 | Entenentspannt {de:entenentspannt} is a pun on 'entspannt' (relaxed). The duck is relaxed, like a pond. |
| E7 | Quak mal! {de:quak_mal} is a pun on 'Guck mal!' (look!). The duck is pointing, with its beak. |
| E8 | Watschel, watschel {de:watschel} means waddle, waddle. It is the sound of a duck walking. This is that walk. |

Detection phrases for a thread reply (lowercase, ß as ss, ü as ue): English "what does that mean", "what does it mean", "what's that mean", "what does that say", "translate", "explain", "meaning?". German "was heisst das", "was bedeutet das", "bedeutet das", "uebersetz". A `:question:` reaction on a duck message with stored German gets a private explanation. Skips: no stored German in the thread, code, a link or program words (Ore, Docs, GitHub, Track, build, error, function, code), a quote, a bot asker, or more than 12 words without a question mark.
